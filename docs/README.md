# Documentação do IndusTrack

O IndusTrack organiza o atendimento de ocorrências em equipamentos industriais, desde a abertura do chamado até o registro da solução. Esta documentação descreve a implementação presente no repositório.

## Guias

| Documento | Conteúdo |
|---|---|
| [Instalação](INSTALACAO.md) | Ambiente, configuração, execução, testes e problemas comuns |
| [Guia de uso](GUIA_DE_USO.md) | Perfis, contas demonstrativas e fluxo de atendimento |
| [Arquitetura](ARCHITECTURE.md) | Organização MVC e responsabilidades do código |
| [Banco de dados](BANCO_DE_DADOS.md) | Entidades, relacionamentos, SQL e dados mockados |
| [API](API.md) | Autenticação, endpoints e exemplos de requisição |
| [Escopo atual](ESCOPO.md) | Funcionalidades disponíveis e próximas etapas |

Para executar o projeto, comece pela instalação. Para apresentar o sistema, siga o roteiro do guia de uso. Para modificar o código, consulte arquitetura, banco de dados e API.
